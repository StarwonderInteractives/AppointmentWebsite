# 💼 Snehansh Appointment Website 

A simple and modern appointment booking website that allows users to directly message Snehansh on WhatsApp with their appointment details. Built using **HTML, CSS, and JavaScript**, hosted for free on **GitHub Pages**.

---

## 🧾 Features
- 📅 **Appointment Form** – Users can enter their name, contact, date, time, and message.
- 💬 **WhatsApp Integration** – Automatically redirects to WhatsApp chat with Snehansh after form submission.
- 🎨 **Modern Design** – Clean UI with responsive layout and subtle styling.
- ☁️ **Free Hosting** – Deployed using GitHub Pages for instant access.

---

## ⚙️ Technologies Used
- **HTML5** – Structure and layout  
- **CSS3** – Styling and responsiveness  
- **JavaScript (Vanilla)** – WhatsApp redirect functionality  
- **GitHub Pages** – Free hosting
